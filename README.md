# SHKWIZI Remote

Управление компьютером с айфона по Wi-Fi: экран ПК в реальном времени («Демка»), кнопки Старт/Стоп, тач и тачпад, клавиатура, поворот экрана.

## Установка
Готовые файлы — в **Releases** (собираются сами после каждого коммита, ~10 минут).

- **Windows:** `SHKWIZI-Remote.exe` → запустить → в брандмауэре нажать «Разрешить» (частная сеть).
- **iPhone:** `SHKWIZI-Remote.ipa` → «Открыть в ESign» → подписать → установить.

## Как пользоваться
1. Запусти программу на ПК — там будут адрес, QR и PIN.
2. На айфоне открой Remote → «Найти компьютер» (или наведи камеру на QR) → введи PIN.
3. «Демка» — видно экран. «Старт» — управляешь, «Стоп» — только смотришь.

Жесты: **Тач** — жмёшь прямо по экрану, удержание = ПКМ. **Тачпад** — водишь пальцем, тап = клик, два пальца = ПКМ / прокрутка. Щипок — зум.

Запуск без exe: `server/START.bat` (нужен Python).
